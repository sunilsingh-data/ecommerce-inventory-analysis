E-Commerce Inventory & Stock Optimization Analysis

Project Overview

This project analyzes an e-commerce inventory dataset to evaluate stock distribution, identify product category volumes, and flag low-stock SKUs to prevent supply chain bottlenecks. 

Tools & Technologies Used
Python (pandas, numpy) for data cleaning and preparation.
SQL (SQLite) for querying relational inventory data and aggregating stock metrics.
Seaborn & Matplotlib for exploratory data visualization.

Key Business Insights
Top Categories: Categories like Kurtas and Kurta Sets dominate the inventory volume, representing the core product offerings.
Inventory Risk: Flagged critical low-stock items (<= 3 units) to assist supply chain teams in timely reordering.

How to Run the Code
1. Download the ecommerce-inventory-analysis notebook from this repository.
2. Open in Jupyter Notebook or VS Code and run.
